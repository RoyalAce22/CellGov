# PPU coverage

Generated by `cellgov dev ppu-coverage-gen`; do not edit by hand. One row per architectural unit of the PPU reference set, with the evidence CellGov holds for it.

Columns:

- **CellGov**: `executes` when some word of the unit decodes and runs; `refuses` and the fault class when every decoded word faults; `not decoded` when no word of the unit decodes; `facility` for a behaviour no single word selects.
- **fuzz**: a fuzz generation descriptor covers the unit; `-` for a facility.
- **reference**: the unit's file under `crates/cellgov_fuzz/tests/fixtures/ppu_reference/`.
- **console**: the console-captured probe cases under `tests/micro/` that run a word of the unit.
- **open results**: the documented sets whose vectors reach a result the documents leave open in the unit, each settled by the `ppu_reference_vectors` capture; `-` when no documented set reaches the unit.
- **title words**: the unit's words in the installed titles' PPU code, from `docs/ppu_census.json`.
